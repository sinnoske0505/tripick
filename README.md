# TRIPICK (트리픽)

돈키호테 화장품을 찍으면 **한국어 제품명 · 원화 가격 · 전성분(표준 성분명)** 을 보여주는 웹앱입니다.
대학교 과제용 MVP+ 버전입니다.

## 무엇이 들어 있나요

| 폴더/파일 | 하는 일 |
| --- | --- |
| `public/` | 휴대폰에 보이는 화면 (시작 → 홈 → 분석 → 결과 → 가격표 판별 → 저장 목록) |
| `api/identify.js` | 1차 촬영: 제품 사진을 Claude가 읽고 제품 DB에서 같은 제품을 찾음 |
| `api/pricetag.js` | 2차 촬영: 가격표 사진을 읽고 5가지 기준으로 판별 |
| `api/info.js` | 오늘 환율, 제품 수 |
| `lib/pricecheck.js` | 판별 기준 (제품 일치·용량 일치·가격 범위 0.5~2배·숫자 읽기·세금 구분) |
| `data/products.json` | 제품 DB 40개 (구글 시트 TRIPICK_제품DB2와 같은 내용) + 환율 |
| `server.js` | 화면과 API를 함께 돌리는 서버 |

## API 키는 어디에 넣나요

**코드에 직접 쓰지 않습니다.** 앱을 올리는 서비스(Vercel 또는 Render)의
"Environment Variables(환경 변수)" 칸에 아래처럼 넣습니다.

- 이름: `ANTHROPIC_API_KEY`
- 값: `sk-ant-…` 로 시작하는 키

(키가 특정 워크스페이스에 묶이지 않았다는 오류가 나오면 `ANTHROPIC_WORKSPACE_ID`도 넣습니다.)

## 키 없이 화면만 보기 (데모 모드)

주소 끝에 `?demo=1` 을 붙이면 키 없이 예시 데이터로 전체 흐름을 볼 수 있습니다.
예: `https://내-앱-주소/?demo=1`

## 내 컴퓨터에서 실행 (선택)

Node.js 20 이상이 필요합니다.

```
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start
```

브라우저에서 http://localhost:3000 을 엽니다. `npm test` 로 판별 로직을 확인할 수 있습니다.
